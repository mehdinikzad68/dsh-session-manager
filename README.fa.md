# dsh-session-manager

فارسی | [English](README.md)

**حذف سشن‌ها برای رابط وب DeepSeek Harness (DSH).**

DSH فقط امکان **Archive** سشن‌ها را دارد و هیچ API حذفی ندارد؛ حذفِ پروژه (Workspace) هم
لاگ‌های سشن را روی دیسک نگه می‌دارد. این پلاگین آن خلأ را پر می‌کند:

- **سایدبار** — منوی «…» هر سشن یک ردیف **حذف…** می‌گیرد (بعد از *Copy Session ID*)، همراه با تأیید.
- **تنظیمات ← Session Manager** — صفحه‌ی مدیریت با فهرست همه‌ی پروژه‌ها و مسیرهای بدون
  پروژه، حجم/تعداد رویداد/تاریخ هر سشن، حذف تکی، حذف گروهی با تیک، و *حذف داده‌های پروژه…*
  (ثبت پروژه + همه‌ی لاگ‌هایش).
- **سبد، نه `rm`** — پوشه‌ی هر سشن **منتقل** می‌شود به
  `$DSH_HOME/trash/sessions/<timestamp>--<id>/` همراه با `manifest.json`، تا از همان صفحه
  قابل **بازگردانی** باشد تا وقتی «خالی‌کردن سبد» را نزده‌اید.

## نحوه کار

نیمه‌ی مرورگری (client) از طریق اسلات‌های رسمی UI (`sidebar.workspaces.session.menu.item`
و `settings.section`) رابط کاربری را ثبت می‌کند و با `fetch` هم‌مبدأ با مسیر
`/session-manager-api/*` که نیمه‌ی Host همین پلاگین روی `ctx.webServer` ثبت کرده صحبت
می‌کند. همان احراز هویت کوکی‌ایِ رابط اصلی (`ctx.connection.requestRejection`) روی این
مسور اعمال می‌شود؛ یعنی فقط صفحه‌ی احراز‌شده‌ی DSH به آن دسترسی دارد.

روند حذف هر سشن: رد اگر فعال است → آرشیو از طریق `workspaceRegistry.archiveSession`
(تا ردیف بلافاصله از نمای پیش‌فرض سایدبار خارج شود) → `rename` پوشه‌ی سشن به سبد →
حذف پوشه‌ی خالی‌شده‌ی پروژه.

## نصب

مستقیم از همین ریپازیتوری (آدرس Git یک spec معتبر برای نصب پلاگین است):

```bash
dsh plugin --profile web add https://github.com/mehdinikzad68/dsh-session-manager
```

یا همان URL را در **Plugins → Add plugin** رابط وب وارد کنید. برای نسخه‌ی محلی،
مسیر پوشه‌ی پکیج را بدهید. نصب خودکار فعال می‌شود: پروفایل‌های `patchReload: live`
بدون ری‌استارت آن را مانت می‌کنند و پروفایل‌های استارتاپی (مثل Desktop) یک ری‌استارت
DSH لازم دارند.

## ایمنی

- سشنِ **فعال** (در حافظه‌ی Host یا رجیستری agent) هرگز حذف نمی‌شود — اول متوقفش کنید.
- حذف یعنی جابه‌جایی به سبد؛ تا «خالی‌کردن سبد» همه‌چیز برگشت‌پذیر است.
- سشن‌های بی‌عنوان، شناسه‌شان نمایش داده می‌شود.
